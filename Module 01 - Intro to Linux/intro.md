# Linux Commands
```
    $ command options arguments
```

Examples
- ls
- ls -l
- ls /dev
- ls -l /dev

*Linux commands are case-sensitive*

# Notes about the syntax
- Multiple options are preceded by One minus sign
```
    ls -alt
```

- Or separated by spaces
```
    ls -a -l -t 
```

- Help available for many commands
```
    ls --help
    man ls
```
